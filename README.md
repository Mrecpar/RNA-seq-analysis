# RNA-seq Analysis

This repository documents my learning and practical experience with RNA-seq data analysis using Linux command-line tools.

## About the project

The workflow includes:
- Sequence data management in Linux
- Read mapping
- SAM file inspection
- SAM to BAM conversion
- BAM sorting
- BAM indexing
- Use of pipes to create efficient workflows

## Tools and skills

- Linux / Bash
- RNA-seq
- Sequence alignment
- SAM/BAM file processing
- Samtools
- Command-line data analysis

I am a Biotechnology Engineer currently pursuing a Master's Degree in Molecular and Cellular Plant Biotechnology at Universitat Politècnica de València (UPV). My professional background includes molecular biology, plant breeding, cytogenetics, RT-PCR, molecular markers and bioinformatics.
